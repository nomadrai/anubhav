# Knowledge-library style

Use the main plain-language ideas of ASD-STE100 for most text, without claiming certification. Relax a rule when a natural explanation is clearer. Aim for about 20 words or fewer per sentence. Use active voice and simple present tense. Explain one idea per sentence and one concept per entry. Define a new term before using it. Prefer common, specific words. Keep one word for one meaning. Avoid idioms, phrasal verbs and vague promises. Use **do not** for warnings. An everyday analogy explains a mechanism; it must not imply a promised result.

Write original explanations, not extracts or close paraphrases from source sites. Keep each language version about 40–120 words. Hindi uses short, spoken sentences and common words. Match the English meaning, uncertainty and limits; do not translate word for word. Aliases may use everyday English, Hindi and Roman Hindi spellings, but explanatory text uses the fixed terms below. Agents may mark content `agent-checked` only; this is not native-speaker or legal review.

## Fixed terms

| English term | Consistent Hindi meaning |
|---|---|
| virtual money | आभासी पैसा; केवल अभ्यास की रकम |
| exposure | दाम बदलने से प्रभावित कुल रकम / जोखिम का आकार |
| leverage | लीवरेज; अपने पैसे के मुकाबले बड़ा जोखिम |
| borrowed money | उधार का पैसा |
| equity | खाते में बचा अपना हिस्सा; company equity means मालिकाना हिस्सा |
| margin | मार्जिन; स्थिति का सहारा देने वाली रकम |
| maintenance margin | स्थिति बनाए रखने के लिए ज़रूरी मार्जिन |
| forced exit / liquidation | मजबूरी का निकास |
| volatility | दाम में उतार-चढ़ाव |
| drawdown | पिछले ऊँचे स्तर से गिरावट |
| recovery | नुकसान के बाद शुरुआती स्तर तक सुधार |
| prediction | पहले का अनुमान; भविष्य का वादा नहीं |
| Hold | केवल ऐप में मौजूदा अभ्यास आगे चलाना |
| Exit | केवल ऐप में अभ्यास की स्थिति बंद करना |
| broker | ब्रोकर; असली लेनदेन का मध्यस्थ |
| registered | संबंधित आधिकारिक रिकॉर्ड में पंजीकृत; मंज़ूरी या सुरक्षा की गारंटी नहीं |
| risk | परिणाम में अनिश्चितता और नुकसान की संभावना |
| return | रकम में बदलाव; निश्चित कमाई नहीं |

No personal recommendation, market forecast, named security/service promotion or invented number. Sources support official facts, not app endorsement. Leave unverified rates, fees, deadlines, legal rules and procedures general. Entry `lintAllow` exceptions identify only explained/warned terms, with specific reasons; they never exempt generated answers or permit recommendations.
